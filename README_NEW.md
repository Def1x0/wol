# Wake-on-LAN Telegram Bot

Telegram-бот для удалённого включения компьютера через Wake-on-LAN из любой точки мира.

## 🚀 Возможности

- Включение компьютера через Telegram с телефона
- Работает через интернет (отправка на внешний IP роутера)
- Простой интерфейс с кнопками
- Бесплатный хостинг на Render.com

## 📋 Требования

- Компьютер подключен через Ethernet (не WiFi)
- Wake-on-LAN включен в BIOS
- На роутере настроен проброс порта UDP 9

## 🔧 Установка на Render.com

1. Форкни этот репозиторий или создай новый
2. Зайди на [render.com](https://render.com)
3. Нажми **New +** → **Background Worker**
4. Подключи свой GitHub репозиторий
5. Render автоматически обнаружит настройки из `render.yaml`
6. Добавь переменную окружения:
   - `TELEGRAM_BOT_TOKEN` - токен твоего Telegram бота
7. Нажми **Create Background Worker**

## ⚙️ Настройки

Измени значения в файле `render.yaml`:

- `TARGET_MAC` - MAC-адрес твоего компьютера
- `ROUTER_IP` - внешний IP адрес твоего роутера
- `WOL_PORT` - порт для WOL (обычно 9)

## 📱 Использование

1. Найди бота в Telegram
2. Отправь `/start`
3. Нажми кнопку "💻 Включить компьютер"
4. Компьютер включится через 5-10 секунд

## 🔐 Безопасность

- Храни токен бота в секрете
- Можно ограничить доступ через `ALLOWED_USER_IDS`
